# UltraVNC - Remote Desktop Control for Windows

## About UltraVNC

UltraVNC is an open-source remote administration tool that lets you control another computer's screen through the VNC protocol. UltraVNC remote control works across local networks and the internet, making it useful for technical support, remote work, and managing machines in different rooms or buildings. UltraVNC screen sharing keeps the experience direct: you see the remote desktop, move the mouse, type on the keyboard, and transfer files without leaving your chair.
